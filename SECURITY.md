# Security Policy

## Reporting a Vulnerability

Do not disclose credentials, tokens, personal data, exploit details, or other sensitive information in a public issue.

Use GitHub's private **Report a vulnerability** / Security Advisory flow if it is available for this repository. MVPConnect does not currently publish a dedicated private security contact. If no private GitHub reporting option is visible, open a minimal public issue asking the maintainer to establish a private reporting channel, without including sensitive details.

## Supported Versions

MVPConnect is pre-release software. Only the current development line on `master` is actively maintained; there is no released-version support matrix.

## Scope

Useful reports include issues involving authentication, authorization, privacy, unintended data exposure, OAuth/provider credentials, or secret handling.
